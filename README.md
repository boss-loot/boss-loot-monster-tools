- A free module for Foundry VTT, D&D 5e, that lets you change the CR of any monster or NPC with a single click. It’s one of the most useful quality-of-life modules a GM can have.

## Features
- Change CR with one click
- Scale Offense & Defense
- Auto scale Multiattack
- Auto scale Initiative
- Preview with helpful tooltips
- Revert to restore the original CR
- Save a token as a new actor after changing its CR
- Fully customizable Guidelines Table (and you can import/export presets)
- Update multiple tokens using the same actor at once

---

## How to open the interface
- Right click a token then click the Monster Tools icon
